# Redimind

Redimind is a shared memory for agents to find reusable knowledge from past project work.

## Language

**Memory entry**:
A durable, confirmed piece of knowledge an agent can retrieve, attributed to a source project and its origin.
_Avoid_: Cache item

**Candidate entry**:
Knowledge proposed for reuse but not yet confirmed by the owner as a memory entry.

**Retired entry**:
A formerly reusable memory entry that is kept for historical context but no longer recommended as current guidance.

**Superseding entry**:
A memory entry that replaces earlier guidance while preserving the relationship to the earlier entry.

**Lesson**:
A memory entry describing an approach tried in project work and what was learned from its outcome.

**Decision**:
A memory entry recording a choice made in project work and the reasons for it.

**Source project**:
The project whose work produced a memory entry; it remains identifiable when that entry is used elsewhere.

**Source reference**:
An identifiable record of the work or observation from which a memory entry arose.

**Applicability conditions**:
The circumstances under which a lesson was observed to work or fail; contrasting lessons may coexist when their conditions differ.
